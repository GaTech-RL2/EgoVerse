# EgoVerse Gen1 repair proposal and initial validation
Use each VRS factory T_device_cpf. Interpolate the original world-device pose at the existing 60 Hz timestamps, then set head_p = p_world_device + R_world_device * t_device_cpf and head_R = R_world_device * R_device_cpf * FLU_FROM_CPF. Do not apply the old RGB-upright head rotation a second time. RGB/depth image upright rectification remains a separate sensor operation.

Use measured MPS wrists for the wrist bones and leave finger landmarks in their measured positions. Preserve solver settings, the existing 1.60 m Gen1 assumption, strict bilateral endpoint validity, original recording splits, and non-bridged continuous segments. CPF is the empirical head reference in this patch; it is not a validated anatomical SMPL joint-15 calibration.

This proves the adapter and retarget conversion execute on these examples; it does not establish visual alignment or training readiness. Next small-scale checks: retain old/head-only/wrist-only/both variants; compare measured hand/robot TCP overlays and A/B/C cloud registration; rebuild three hd2 clouds/DINO/FK on identical timestamp windows; audit masks, finite values, FK and train-only normalization provenance; complete real-loader checks and any intended smoke before claiming training readiness.
