# Report publication

`publish_report.py` copies a complete private phase report and changes only declared absolute local repository-root prefixes in JSON path strings. Markdown, CSV and PNG files remain byte-for-byte copies. It verifies the generated file manifest and complete phase/case count before publication, preserves JSON bytes outside changed string tokens, and rebuilds the report file manifest from the public bytes.

The exact prefix mapping and original path values remain in an exclusive, mode-600 private receipt. Public `publication.json` records that receipt's hash, each prefix's hash and byte length, replacement counts, all original/public file hashes, and the exact helper source snapshot. It does not publish the local prefix itself. Measurements, source-artifact hashes and audit claims remain unchanged. Publication is not a new outcome or numerical audit.

After activating emimic, run from the repository root:

```sh
python astra_reversal/reports/phase_interpolation/report_publication/publish_report.py \
  --input astra_reversal/.deps/interpolation-development-recovery-v2/complete-report \
  --output astra_reversal/reports/phase_interpolation/development/results \
  --private-receipt astra_reversal/.deps/interpolation-development-recovery-v2/report-publication-private.json \
  --local-root "$PWD" \
  --phase development \
  --expected-report-sha256 aabca47e36b8d68a71c36c4aaa6f82af3994885486e9eab119d5f2c326f564d6
```

For evaluation, use its completed private report, a new evaluation results directory/private receipt, `--phase evaluation`, and the verified evaluation report hash. `--local-root` may be repeated for distinct checkouts of the same repository. Unexpected local paths, prefixes inside non-path strings, altered input checksums, extra files and existing destinations fail closed. No report is generated by this helper; it makes no network, model, simulator or provider calls.

Focused verification uses synthetic temporary files only:

```sh
PYTHONPATH=. pytest -q tests/unit/test_astra_interpolation_publication.py
```
