The learned text selector improved OOD success from **15/40 (37.5%) to 19/40 (47.5%)**, but the small flow correction did not reliably improve control. Replaying a successful teacher's prescribed text-intervention schedule performed best: **27/40 (67.5%)**, with twelve recoveries and no lost native successes. This is evidence that the recorded interventions transfer to new resets of these compositions; the first distillation recipe retains only part of that benefit.

This recipe asks whether prior Astra corrections can become an autonomous policy improvement. **Astra is not called during the new training or evaluation**, so there is no new Astra prompt, reasoning effort or visual feedback loop. The teacher's contribution is the recorded successful TEI/TLI program and its actually executed actions. The historical [prompts and harness](../representation_steering/METHODS.md) and [literal prompt snapshots](../representation_steering/prompts/phase_interpolation.json) remain available. The deployed selector sees current environment images through frozen native visual features, the original instruction's native features and robot state. This experiment changes no raw pixels or visual embeddings, and does not test VEI/VLI again.

Training admits twelve completed successful Astra text-intervention trajectories across eight compositions: ten from the seed-29 phase study and two verified seed-19 pilot rescues. They contain 1,248 executed actions and 255 replan windows. Seven historical native successes add 774 actions and 158 windows. Four new native anchor rollouts on standard tasks 0–3, reset 0, all succeed and add 932 actions and 188 windows. The final corpus is **23 trajectories, 2,954 actions and 601 windows**. Windows and eight noise/time draws per window are correlated training samples, not additional demonstrations. The two pilot trajectories have individually verified partial-archive provenance, as distinguished in the frozen corpus design.

The frozen base is `lerobot/pi05_libero_base`, revision `a217bfd3b14673cf2ce597e69997ab21866438dd`, with the exact OpenPI LIBERO input profile and quantile normalization. The loader strictly binds all 812 checkpoint tensors. Native inference uses horizon 10, seven physical channels in 32 padded channels, ten Euler steps and five executed actions per replan; TF32 is disabled. The base receives no backward passes. Its parameter hash is identical before and after learning.

The **535,321-parameter selector** pools valid visual slots and instruction-only slots from the native final prefix layer, then appends the eight-dimensional robot state. Its 4,104-dimensional input has no explicit action clock, task ID, future outcome, privileged simulator object state or teacher-edited hidden state. The original instruction can still identify a familiar composition. An MLP with hidden widths 128 and 64 predicts an intervention gate, one of twelve operator/source-pair classes and that class's interpolation coefficient. It refreshes every 25 executed actions and holds its choice between five-action replans. Gate scores strictly above 0.5 intervene; ties use native. This gate imitates successful teacher use and is not a calibrated failure probability or counterfactual estimate of intervention benefit.

TEI replaces eligible instruction embeddings with `(1 − α) E(A) + α E(B)`. TLI adds `(1 − 2α) (T_A − T_B)` to eligible instruction hidden states after blocks 0–16, using the frozen standard-demonstration text banks. The original observation and protected token slots remain the inputs. TLI α = 0.5 is neutral; TEI α = 0 selects source A and is not a native fallback. The selector predicts the operator, pair and coefficient; it does not generate a new natural-language prompt online. It receives 1,000 AdamW updates, learning rate 0.001, batch size 64 and weight decay 0.0001, with balanced positive/native sampling and equal trajectory weighting within those groups.

The **7,175-parameter flow head** is a zero-initialized linear map from each 1,024-dimensional final action-expert hidden state to seven physical channels, bounded as `δv = 0.5 tanh((Wh + b) / 0.5)`. It adds this residual to the native vector field on the first five action rows. At the same flow state, rows 5–9 and padded channels have no direct residual; later attention and integration can propagate effects. Both head arms preserve the original image and language conditioning. The gated arm enables this same head with the selector's gate and applies no additional TEI/TLI edit.

For each correction window, the actually executed controller prefix is mapped through native normalization into a masked flow-matching target. With `x_t = t ε + (1 − t) x_0`, the velocity target is `ε − x_0`. Eight fixed Gaussian/time draws use the native time distribution `Beta(1.5, 1) × 0.999 + 0.001`. Only executed rows and seven physical channels are supervised. A fresh native sample fills the unobserved physical suffix and clean padded channels are zero; this is an explicit imputation approximation because the model attends across action rows. Unexecuted predicted actions are never labeled as demonstrations. Native anchors penalize nonzero residuals under original conditioning. The head receives 1,000 Adam updates, learning rate 0.0001, batch size 128, anchor weight 1, L2 weight 0.0001 and gradient clipping at 1.

The recorded schedule is a control for memorizing a useful teacher program. Each familiar task instruction selects one successful teacher by a fixed priority and tie-break declared before evaluation. Its latest preceding choice is replayed by absolute executed-action step; its final choice is held after the teacher's successful endpoint. Tasks without a teacher use native. The learned arms perform no teacher-trajectory retrieval at evaluation, although TLI still uses its fixed standard-demo text banks.

There is **no test-time flow inversion or iterative Astra search in this recipe**. Offline learning changes a small part of the vector field; deployment uses ordinary native flow integration. The online proposal/reversal/judgment loop remains a separate experiment. This result should not be presented as evidence that Astra learned to diagnose and correct a fresh failure online.

Recorded training fit improves: the selector's first and last sampled minibatch objectives are 3.23548 and 0.003122; these are different minibatches, not held-out measurements. The head's masked MSE changes from 0.144120 to 0.107019, with final native-anchor MSE 0.004274. The poorer head rollout result demonstrates why that loss decrease is insufficient evidence of better control. Both saved modules reload strictly, and the head's saved Adam counters show 1,000 actual updates. Real-checkpoint upstream-native, feature-capture and zero-head parity probes all have zero maximum absolute error. Deployment checks verify that active head calls use the trained weights and finite bounded residuals.

The strongest next hypothesis is to **distill the successful text program more faithfully before enlarging action learning**. A controlled follow-up could compare a task-conditioned constant edit, the recorded schedule, and a compact recurrent phase-aware selector, with whole teacher episodes held together and a separate validation set. The present selector sees mean-pooled features once every 25 actions; that may lose useful phase or source-pair information, but this run does not isolate the cause. The schedule's eight extra successes give this comparison a concrete target.

A second hypothesis is to **learn intervention benefit from paired continuations**. On a separate acquisition split, restore the same simulator state and compare native versus a fixed teacher correction under matched noise. Train the gate on resulting benefit/harm, including failed and unnecessary corrections, then freeze it before a new evaluation. This would address the current gate's support-only labels. For action learning, compare the present masked executed-prefix objective with same-state teacher-vector-field distillation or a condition-aware low-rank residual, while keeping native anchors and the ID panel. These are proposed experiments, not measured improvements; more correction coverage and held-out compositions are needed before claiming broader generalization.
