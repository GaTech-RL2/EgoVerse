What do TEI, TLI and a flow correction actually change?
TEI · TEXT EMBEDDING INTERPOLATION

Mix the instruction’s input embeddings.

E ← (1 − α) E(A) + α E(B)

Two source prompts form a new instruction representation before the language blocks. α = 0 chooses A; α = 1 chooses B.

TLI · TEXT LATENT INTERPOLATION

Add a direction inside the language model.

h ← h + (1 − 2α)(TA − TB)

A stored text-latent difference edits eligible instruction slots after blocks 0–16. α = 0.5 is neutral.

FLOW HEAD · VELOCITY RESIDUAL

Nudge the action vector field.

v ← vnative + 0.5 tanh((Wh + b) / 0.5)

The head directly changes the first five physical action rows. Images and language conditioning stay original.

This run uses ordinary flow integration after offline learning. It does not perform test-time flow inversion, fresh Astra reasoning, pixel edits or visual-embedding interpolation.
