TEACHER RECIPE / V2 → V6

Revisions tied to observed failures

V2 uses clipped RTC weighting, offering two projected candidates and one full-gradient candidate. Diagnosis receives temporal images and summaries from earlier collection attempts.

V3 permits a gripper sign change within the original controller bounds. V4 adds a choice of motor targets or a phase instruction, generating one prompt-conditioned candidate and two TEI mixes. Original task inputs are retained for learning and autonomous evaluation.

V5 tells Astra that only the first five actions execute and corrects supervised training to use the seven real action channels. V1–V4 included padding in their loss; their results retain that distinction.

V6 adds two contrastive TLI candidates and returns recent verifier rejections to diagnosis. These changes are prospective until a V6 rollout is recorded.

A probe reduced target error by 68.1% with projected RTC guidance, versus 0.76% with the original taper. This is not a success-rate result.
RL COMPARATORS / PINNED RLINF

DSRL + flow-SDE PPO

DSRL learns a noise-selection policy with SAC while freezing the exact native decoder. Its starting noise distribution differs from native π0.5.

PPO uses the released stochastic flow sampler and likelihood recomputation, training the action expert and value head. Converted weights must pass native parity and backward checks.

Both use the common OOD reset schedule. Serial harness overrides and limited tuning must be considered before making a claim about strong RL.
