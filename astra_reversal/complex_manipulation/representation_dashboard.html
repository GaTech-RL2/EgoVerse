02 / How intervention works

One teacher, two places to intervene

A / TEI · Text embedding interpolation

Change what enters the transformer

E′ = (1 − α) Egoal + α align(Esubgoal)

Interpolate only the original instruction’s input embedding slots. α = 0 keeps the native input; α = 1 uses the aligned subgoal embeddings. The edited prefix then runs through the native transformer and action expert.

The action expert and ten-step flow sampler retain their original weights.

B / TLI · Text latent interpolation

Change intermediate text states

h′ℓ = hℓ + (1 − 2α) [align(Tsubgoal,ℓ) − Tgoal,ℓ]

Keep the target input. After transformer blocks 0–16, add a difference between native source text states. α = .5 is neutral; .25 or 0 moves toward the subgoal. Later attention carries the change into the cache used by the action expert.

The last block is not edited because its key/value cache already exists.

These are online subgoal representations, recomputed on the current real cameras and state at every policy replan. They are not extracted from demonstration banks. Source instruction slots are aligned in order, truncated or zero-padded to the target slots. Direct edits preserve state tokens, delimiters, attention masks and positions. Later attention can change other hidden representations.

05 / Traceability
Validation and retained failures
Before any environment is constructed, the runner compares the native transformer cache and neutral TEI/TLI actions at identical noise, checks active steering sensitivity, and verifies that the native output remains unchanged afterward. The RNG is restored before task execution. The maximum neutral-action tolerance remains 10⁻⁵. Both operators are measured, but only the scheduled arm and common native checks gate its execution. Auxiliary failures remain visible; they must be resolved before that operator runs.
The first checks exposed a difference caused by compiling a constant flow timestep instead of passing the baseline’s dynamic step count. After that correction, neutral actions matched exactly; a second correction prevented bfloat16 endpoint rounding from appearing in the neutral TEI edit counter. A later run exposed another neutral TLI mismatch; zero-delta block writes were then made explicit no-ops. All these receipts remain included. The earlier stopped validation and video-preparation allocations are retained below. They produced no policy rollout actions or rollout teacher usage; video preparation failed after one constructor setup reset, which remains counted.
Scope and limits
This screen tests whether representation interventions help two difficult seen RoboCasa tasks under a small matched budget. A nonzero latent edit or changed prediction is an implementation check, not evidence of higher task success. A successful episode would establish a result for its recorded reset, not broad generalization.
The requested guidance-only / learning-only / combined / neither comparison at 1, 2, 4, 8 and 16 collection episodes remains a separate experiment. This report contains no learned policy improvement. The earlier Bench2Dex native probes are in the previous dashboard.
