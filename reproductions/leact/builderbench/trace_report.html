What the results say so far

Frontier warmstart SFT improves the student substantially. The first LeAct round increases fully solved rollouts from 40/306 to 51/306, while average cube progress stays almost unchanged. Progress improves on demonstrated tasks and declines on held-out tasks. That is a mixed result, not yet evidence of a general LeAct improvement.

Teacher reference, speed interpretation, and reproduction scope

GPT-6 Astra fully solved 23/51 collected rollouts (45.1%) at seed 0, with 62.3% average cube progress. Its 23 solved tasks define the demonstrated partition; the other 28 define held-out tasks. This split is conditioned on teacher success, not a random generalization split. Only 153 admitted teacher action steps supplied the initial BC corpus, or 306 forward/backward examples for joint warmstart. This is a small-corpus extension using GPT-6, not an exact reproduction of the paper’s original data and task split.

Online timing averages include different model-generated trajectories and failures. Student timing measures vLLM generation on one H100 per worker; teacher timing includes remote API/network delay. Model loading is excluded. Do not interpret these as a controlled student–teacher speedup: matched-observation timing is a separate pending experiment. The major shortening occurs during warmstart; LeAct’s average output length is nearly the same as warmstart’s.

Both rollouts start from the same recorded observation. After different actions, their states can diverge. Equal decision numbers do not imply equal observations or simulation time. The models use different output formats; only the teacher emits a public decision summary.

How an explanation gets admitted to LeAct SFT

Here the warmstarted student receives the expert action and generates a backward explanation. A forward action is then sampled with that explanation and scored against the expert. A positive improvement over an action-only baseline makes the candidate eligible; up to two candidates per state are retained after context checks.

These are training candidates, not autonomous final-student rollouts. The backward generator sees the target action. Positive action reward does not establish that every sentence in the explanation is correct.

This round admitted 94 explanations → 188 forward/backward SFT examples. The seven states below illustrate admissions and rejections; they are not a random sample or a separate accuracy estimate.

How to read these examples
  • The six rollout cases deliberately include gains, regressions, and failures. Aggregate conclusions come from the score table, not from these selected examples.
  • Teacher text is the public explanation returned with an action. Student text is the captured output from the open-weight model. No provider-private reasoning is included.
  • All rollout examples use seed 0. The backward training examples come from the separate seed-1 expert collection used for the first iterative round.
  • Invalid responses and context overflows remain failures in the reported denominator. There is no action repair, history truncation, or hidden best-of-N selection in the autonomous traces.
  • Each expandable provenance record contains hashes and original source paths. Videos are post-hoc MuJoCo replays, validated against every logged action’s public observation and outcome. They omit model inference pauses and are not recordings of live inference. The page makes no network requests and can be opened directly from disk.
