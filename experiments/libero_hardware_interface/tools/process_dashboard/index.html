What stays shared
All actors get the task instruction, source search/read, a Python scratchpad and finish. They inspect before acting, use bounded commands, verify progress from allowed observations and correct rejected calls. They cannot query hidden simulator state or the evaluator’s success label. All three directly receive camera images.
The current LIBERO cohort has no experiment token or wall-time cap. It retains the 1,000-native-step episode horizon, at most 10 repeated steps per command, provider request limits and scratch isolation.

What a reattempt means here
Robot behavior
Astra can observe again, change commands, move back or change the gripper command within the same episode. The full sequence is preserved. Gripper transitions help navigation; they are not automatically scored as grasp attempts.
Rejected tool → correction
The proxy returns a reason when a call is invalid. The next accepted tool call is marked. It may be a corrected command or another observation; acceptance alone does not prove task recovery.
Provider transport retry
A transient inference error can resend an unexecuted model request up to three times in this cohort. This does not reset the robot or repeat an already-dispatched action. Actual retry events appear separately when recorded.

      

      

        
TRACEABLE TO THE ARCHIVES
What this recording can establish
Every exported trial was checked against its archive receipt and append-only event hash chain before this dashboard was built.

        

        
Recorded and preserved
  • Actor system prompts, task instructions, delivered tool schemas and recorded observer prompts.
  • Emitted tool calls, Python snippets, tool results, source reads, every applied native action, validation errors and provider errors.
  • Original PNG bytes for logged actor camera observations, with timestamps and simulator steps.
  • Outcome records, independent replay receipts, archive paths, event hashes and source provenance.
Representation and gaps
  • Videos show saved observations at a condensed cadence. They do not invent camera frames between reads.
  • Private reasoning is not available as readable text. Opaque encrypted payloads are omitted with their byte counts and hashes; emitted messages and commands are retained.
  • This cohort stores request-history hashes to avoid duplicating growing input histories. The dashboard preserves those hashes and exact recorded outputs; it does not invent missing request bytes.
  • Observer-only image inputs may be hashed rather than stored. B’s recorded descriptions are exact. The recorder displays logged actor images, never pretends a missing observer image was captured.
  • JSON PNG payloads are externalized to local files. Repeated prompts and tool schemas use local content references. These are documented export transformations; original event-file hashes remain in each receipt.
  • Records inside a rollout are not independent trials. Historical runs, fresh LIBERO pilots and RoboCasa commissioning smokes are kept separate. A replay pass verifies the trace; it does not imply task success.

        
Reproduce or inspect
Open the JSON recording beside any trial, inspect manifest.json, or verify package files against SHA256SUMS.json. All media and code needed to view the dashboard are in this folder. No network connection is required.
