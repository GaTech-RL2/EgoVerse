2 · The 21 per-joint distances

Every joint gives one number. The metric's whole job is turning this 21-vector into one scalar — and which reduction you pick is the design choice.

3 · Reducing the vector to a scalar

d = ( ‖Δp1‖, ‖Δp2‖, …, ‖Δp21‖ )   ← the bars above
L∞ = maxi di = 37.87 mm   — token advances once ANY joint moved D → bounds per-joint error
L2   = √Σ di² = 79.12 mm
L1-mean = (1/21) Σ di = 14.90 mm
L1-sum = Σ di = 313.0 mm   — the Epose form; ~21× inflated because joints move together

4 · Optional rotation term

The wrist also rotated by θ = 15.4° over this step. Epose adds a rotation distance per part; μ is a true metric on SO(3), so the sum is still a valid arc length.

μ(R, R̂) = ½ ‖(RTR̂)1/2 − I‖F = √2 sin(θ/4) = 0.09475  (dimensionless)
λ·μ with λ = 2√2·r, r = 8cm → 21.44 mm  — the arc a point 8cm from the wrist would trace
step = ‖d‖∞ + λμ = 37.87 + 21.44 = 59.31 mm

5 · Steps accumulate into arc length; every D metres cuts a token

Cumulative L∞ distance over the next few seconds. Horizontal lines are token boundaries at multiples of D = 0.45 m; each token is resampled to M = 30 waypoints, so spacing h = D/(M−1) = 15.5 mm.
